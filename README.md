# Daffa Naufal Mumtaz Heryadi — Portfolio

A bilingual personal portfolio built with Astro, TypeScript, Tailwind CSS, and Plus Jakarta Sans.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated static site is written to `dist/`.

## GitHub Pages

This project is configured for the root domain `https://daffamumtaz.github.io`. The included GitHub
Actions workflow builds and deploys every push to `main`.

Use `daffamumtaz.github.io` as the GitHub repository name. The local folder can remain
`porto-daffamumtaz`.
